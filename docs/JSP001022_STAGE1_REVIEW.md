## 本轮要明确表达的数学结果

设 `c > 0`、整数 `2 <= M <= N`。对非负数列 `u_n`，令 `S(t)=sum_{k=0}^t u_k`、`B_M=S(M-1)`，并假设 `S(n) >= c log n` 在 `M <= n <= N` 上成立。正文先用离散分部求和得到

```math
c\sum_{q=M+1}^{N}\frac{\log q-\log(q-1)}{\log q}
-\frac{B_M}{\log M}
\leq \sum_{n=2}^{N}\frac{u_n}{\log n}.
```

再利用离散和等于 `log log N + O_M(1)`，得到集合倒数权的下界 `W_A(N) >= c log log N - C`，其中 `C` 与 `N` 无关。由取整及端点误差趋零，得到所需的密度正性转移。

这里必须区分三件事：

1. 正文在数学层面说明了更强的常数比较；扩展的 `jsp_001022_density_bridge` 对外只输出正性蕴含，不能把正文强化陈述说成该 Lean 声明已经证明的类型。
2. 离散主项的有界误差是 Prim 的已有结果；plby 也已有较强的密度比较，不能写成这次首次解决了密度桥梁。
3. 桥梁中使用辅助常数 `c` 或 `c/2`，不意味着最终链计数损失常数。最终定理的下界仍是原集合完整的加权上密度。
